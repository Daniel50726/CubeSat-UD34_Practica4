# Acuerdos de interfaces

Conservar los identificadores IF de la práctica 3. Cada tabla debe documentar los extremos conectados, las señales, su dirección, los niveles eléctricos, las tasas, los estados de arranque y las condiciones de alimentación.

Para conectores, incluir referencia exacta, número de contacto, red, función, destino, corriente o parámetros de RF cuando correspondan, revisión y estado del acuerdo. No considerar definitiva una numeración sin comprobar ambos extremos.
